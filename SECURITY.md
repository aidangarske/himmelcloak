# Security Policy

## Supported versions

Himmelcloak is in early development and has no stable release yet. Security
fixes are made in the current development code; older commits are not maintained
as separate supported versions.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting form](https://github.com/aidangarske/himmelcloak/security/advisories/new)
to report a security issue. Do not open a public issue or pull request for an
unfixed vulnerability.

Include a description of the issue, affected version or commit, steps to
reproduce it, its possible impact, and any known workaround. Please avoid
including real credentials, tokens, or private keys unless the maintainers
arrange a secure way to share them.

## Disclosure

Maintainers will review the report, work with the reporter on a fix, and
coordinate public disclosure when appropriate. Response times and release
dates may vary with the issue and the project's development stage.
