# Contributing to Himmelcloak

Thank you for your interest in contributing. Himmelcloak is a community project
for native authentication with self-hosted Keycloak. This guide outlines ways
to get involved.

## How to contribute

- Report bugs through [GitHub Issues](https://github.com/aidangarske/himmelcloak/issues).
- Suggest features or improvements.
- Improve the [documentation](docs/) or tests.
- Submit code through pull requests.
- Help review issues and pull requests.

Please be respectful when working with other contributors. For code changes,
use a focused feature branch and briefly explain the change in your pull
request. The [development plan](docs/Development-Plan.md) outlines upcoming
work.

For security issues, follow the [Security Policy](SECURITY.md) instead of
opening a public issue.
